# Machine Learning Mini Projects Portfolio

Welcome! This repository showcases my journey through the **Machine Learning (Spring 1403)** course at K. N. Toosi University of Technology. It features four mini-projects where I explored fundamental and advanced ML concepts.

---

## About This Portfolio

This portfolio demonstrates my practical application of machine learning techniques, from foundational classification and regression to more advanced deep reinforcement learning. Each project section provides a brief overview of the goals, what I learned, the tools used, and links to the detailed project READMEs.

---

## Projects

###  **Mini Project 1: Machine Learning Fundamentals**

*   **Focus:** Introduction to linear classification, feature engineering from signals, and regression techniques.
*   **Key Areas:**
    *   Linear classifiers and dataset generation.
    *   Feature extraction and manual model implementation.
    *   Regression using Least Squares (LS), Recursive Least Squares (RLS), and Weighted Least Squares (WLS).
*   [**See Project 1 Details**](./Project_1/README.md) *(Link to your Project 1 README)*

###  **Mini Project 2: Neural Networks & Ensemble Methods**

*   **Focus:** Diving deeper into neural networks, classification metrics, and tree-based ensemble models.
*   **Key Areas:**
    *   Activation functions (Sigmoid, ReLU, ELU) and simple neural networks.
    *   Multilayer Perceptrons (MLP) for fault detection.
    *   Decision Trees, AdaBoost, and Random Forests.
    *   Naive Bayes classifier for health-related data.
*   [**See Project 2 Details**](./Project_2/README.md) *(Link to your Project 2 README)*

###  **Mini Project 3: SVMs & Dimensionality Reduction**

*   **Focus:** Hands-on experience with Support Vector Machines (SVMs) and Principal Component Analysis (PCA).
*   **Key Areas:**
    *   Data preprocessing and PCA for dimensionality reduction.
    *   Linear and Polynomial SVM implementations.
    *   Implementing SVM from scratch using quadratic programming.
*   [**See Project 3 Details**](./Project_3/README.md) *(Link to your Project 3 README)*

###  **Mini Project 4: Deep Reinforcement Learning Adventures**

*   **Focus:** Exploring Deep Reinforcement Learning with DQN and DDQN.
*   **Key Areas:**
    *   Implementing Deep Q-Networks (DQN).
    *   Training agents on environments and analyzing performance.
    *   Implementing Double Deep Q-Networks (DDQN) and achieving environment solutions.
    *   Includes performance plots and training videos.
*   [**See Project 4 Details**](./Project_4/README.md) *(Link to your Project 4 README)*
